Investigación de Bootstrap 5

Componentes utilizados para mejorar la experiencia de usuario en CampusFlow.

Tabla comparativa

Nombre Descripción Ejemplo en código HTML
Popover Ventana emergente que presenta información adicional sobre una actividad. <button data-bs-toggle="popover" data-bs-content="Clase de programación"> Detalles</button>
Tooltip Mensaje breve que explica la función de un botón al pasar el cursor o enfocarlo. <button data-bs-toggle="tooltip" data-bs-title="Agregar actividad"> Agregar</button>
Toast Notificación temporal que confirma acciones y muestra avisos. <div class="toast" role="status"> <div class="toast-body"> Guardado correctamente </div></div>

Los ejemplos muestran la estructura HTML básica. La aplicación utiliza JavaScript para inicializar y mostrar estos componentes.

Aplicación en el proyecto

CampusFlow utiliza Popovers para consultar detalles de las actividades, Tooltips para explicar botones y Toasts para confirmar acciones o advertir sobre conflictos de horarios.

Estos componentes ayudan a evitar confusiones, presentan información sin saturar la pantalla y permiten que el estudiante comprenda mejor el funcionamiento de la aplicación.
